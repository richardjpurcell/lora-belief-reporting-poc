## Manual bench checklist

Before attempting the physical replay:

1. Open each firmware sketch in Arduino IDE or the selected flashing workflow.
2. Confirm `RUN_ID = "R34"`.
3. Confirm `TX_ID` and `NODE_ID` match the transmitter label.
4. Confirm `STARTUP_OFFSET_MS` matches the table in this note.
5. Flash all ten transmitters.
6. Mount each SD card.
7. Confirm the volume label is `LORA_TXA` through `LORA_TXJ`.
8. Remove any old `schedule.csv` or `SCHEDULE.CSV`.
9. Copy the matching Run 034 SD schedule as `schedule.csv`.
10. Eject cards cleanly.
11. Install each card in the matching transmitter.
12. Prepare the receiver log capture before powering the transmitters.

- `logs/rx_run_034_ten_transmitter_sd_replay_candidate.csv`
